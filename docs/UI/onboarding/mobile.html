Guia interativo

Olá! Vou ajudar-te a configurar a tua conta em menos de 5 minutos. Primeiro, conecta a tua conta do GitHub colando o teu Personal Access Token (PAT) ou escolhendo o teu board.

Aviso: Não digas o teu token em voz alta: cola-o no campo.

Aviso de Privacidade: O PulseBot e os relatórios utilizam IA externa (Google Gemini): mensagens, metadados de tarefas e contexto do cliente. A integração não lê ficheiros de código. Evita dados sensíveis nos textos.
